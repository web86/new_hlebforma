# Схема страниц и сценарии прототипа Hleb-Forma 2.0

> **Статус:** wireframe v0.1, для обсуждения и дальнейшей реализации; не финальные тексты, цены или дизайн.  
> **Дата:** 22 ноября 2026 года.  
> **Прототип:** [открыть HTML](../prototype/index.html) · [README](../prototype/README.md).  
> **Основа:** [аудит](./LEGACY_SITE_AUDIT.md), [план миграции](./MIGRATION_PLAN.md), [дизайн-бриф](./PROTOTYPE_BRIEF.md), [маркетинг](./MARKETING_STRATEGY.md).

## 1. Главная идея

**Эволюционный редизайн.** Покупатель узнаёт Hleb-Forma по названию, тематике ротанговых корзин, знакомым категориям и понятному каталогу, но теперь видит удобный выбор по **весу теста** и отдельный маршрут для **оптовой закупки**. Не пытаемся воспроизвести Ozon: специализация и помощь в выборе важнее универсальной витрины.

В прототипе используются **условные рисунки вместо реальных товарных фото** и небольшая демонстрационная выборка из старого ассортимента (BN 10, BN 01, BN 06, BN 32, BN 28). Перед production подставить оригинальные фотографии и проверенные актуальные цену, наличие, характеристики и комплектацию.

## 4. Экран A — главная

**Цель:** первый посетитель за 5 секунд понимает предложение, старый клиент сразу находит каталог, пекарня видит путь в опт.

~~~text
[Шапка со знакомыми разделами]
┌────────────────────────────────────────────────────────────────────┐
│ КОРЗИНКИ ДЛЯ РАССТОЙКИ ХЛЕБА     [крупное фото реальных корзинок] │
│ Выберите форму под ваше тесто                                      │
│ [Подобрать корзинку]  [Для пекарен и оптовиков]                    │
└────────────────────────────────────────────────────────────────────┘
[Подбор: вес теста ▾] [форма ▾] [Показать товары]
[Категории: круглые | овальные | багетные | фигурные | инструменты]
[Популярные товары: фото, вместимость, размер, цена, CTA]
[Для пекарен: ассортимент партиями / запросить предложение]
[Руководства по выбору и уходу → связанные товары]
[Отзывы из реального магазина]
[Подписка только по согласию]
[Футер: доставка, реквизиты, политика, контакты]
~~~

**Проверить:** визуальный вес блока B2B — не конкурирует с основной розничной кнопкой, но хорошо заметен; изображения и текст не затрудняют мобильную загрузку.

## 5. Экран B — каталог / категория

**Цель:** не искать по артикулам вслепую, а выбрать по задаче.

~~~text
[Хлебные крошки → Каталог]    H1: Корзинки для расстойки хлеба
[Короткое объяснение]         [Категории]
┌─────────────────┬──────────────────────────────────────────────────┐
│ Вес теста ▾     │ [фото]       [фото]       [фото]                  │
│ Форма ▾         │ BN 10        BN 01        BN 06                  │
│ Цена ▾*         │ 500–550 г    700–800 г    500–550 г             │
│ Наличие ▾*      │ 25×15×8      22×8,5       55×10×7               │
│                 │ цена  [В корзину] [Подробности]                  │
└─────────────────┴──────────────────────────────────────────────────┘
~~~

\`*\` Только после подключения реальных полей. На мобильном — компактные кнопки фильтра/сортировки, 1–2 карточки в ряд. **При маленьком каталоге сложный mFilter не обязателен.**

## 6. Экран C — карточка товара

**Цель:** дать клиенту достаточно информации для выбора, не заставляя читать длинный текст.

~~~text
[Главная / Каталог / Категория / BN 10]
┌───────────────────────────────┬────────────────────────────────────┐
│ [большое фото корзинки]       │ Овальная корзинка BN 10           │
│ [галерея фото]                │ Для 500–550 г теста              │
│                               │ 25×15×8 см • ротанг • артикул     │
│                               │ Цена / наличие / кол-во          │
│                               │ [В корзину]                      │
│                               │ [Запросить оптовую цену]          │
│                               │ Доставка и оплата: по факту      │
└───────────────────────────────┴────────────────────────────────────┘
[Как выбрать размер?] [Описание] [Безопасный уход] [Отзывы]
[С этим товаром выбирают] → аксессуары / товары
~~~

**Важно:** оптовая кнопка переносит SKU и количество в форму, а не открывает пустую анкету. Маркетинговые обещания (например, чехол в комплекте) только по проверенным данным.

## 7. Экран D — оптовым покупателям

**Цель:** превратить посещение в квалифицированную заявку.

~~~text
[H1: Корзинки для расстойки хлеба оптом]
[Для пекарен: подбор форм и инструментов под ваш ассортимент]
[Запросить предложение] [Смотреть каталог]
[Что можно заказать: корзинки / инструменты / аксессуары]
[Как работаем: запрос → уточнение → предложение → согласование]
┌─────────────────────────────────────────┐
│ Заявка:                                │
│ Товар/SKU [___]  Количество [___]      │
│ Имя [___]  Email / Телефон [___]       │
│ Организация [необяз.]                  │
│ Комментарий [_________________]        │
│ [✓ обязательное согласие ПДн]          │
│ [Отправить запрос]                     │
└─────────────────────────────────────────┘
[FAQ: мин.партия, цены, доставка, документы — после согласования]
~~~

Данные заявки должны сохраняться **в БД**, а email и Telegram являются каналами уведомления. Защита от дублей, спама, повторная доставка. В **статическом прототипе отправки на сервер нет**.

## 8. Экран E — корзина и оформление заказа

**Цель:** минимум неопределённости и поля только по необходимости.

~~~text
[Шаг 1. Корзина: товар / количество / цена / удалить]
[Шаг 2. Контакты и адрес / регион]
[Шаг 3. Доставка: СДЭК / ПВЗ + рассчитанная цена]
[Шаг 4. Оплата: ЮKassa]
[ИТОГО: товары + доставка − скидки]     [Оформить заказ]
[Понятные ошибки] [Подтверждение / письмо]
~~~

В прототипе можно менять количество и видеть демонстрационный итог **без реального расчёта доставки, API СДЭК, оплаты и оформления заказа**. Реальная сумма сервера всегда авторитетнее клиентского предварительного расчёта.

## 9. Остальные страницы — согласованный минимальный набор

| Экран | Задача | Особенность |
|---|---|---|
| Блог / статья | Отвечать на вопросы и вести в каталог | Подбор по весу теста, уход, сравнения, реальные ссылки |
| Доставка/оплата/возврат | Доверие перед покупкой | Исправить противоречия с текущим сайтом и проверить реквизиты |
| Контакты | Простая связь | Действующие реквизиты, подтверждённый адрес |
| Кабинет | Возврат старых клиентов | Миграция заказов и вход со старым паролем |
| Результаты поиска / 404 | Не терять пользователя | Подсказки, похожие категории и ссылка на каталог |

## 10. Дизайн-направление

- Сохраняем бренд и знакомые названия категорий; новый визуальный стиль — **светлый, натуральный, тёплый**, без визуального шума.
- Дизайн-токены прототипа: тёплый фон, тёмные тексты, коричнево-терракотовый CTA, умеренные скругления; **палитра предварительная**, перед версткой сверить старый логотип.
- Товары — реальные фотографии из старого магазина; **в текущем демонстрационном HTML рисованные заглушки**, чтобы не путать иллюстрации с фотографиями продукции.
- Основные метрики: клики «Подобрать», посещение карточки, добавление в корзину, начало checkout, покупка; для B2B — переходы на «Оптовикам», успешные заявки.

## 11. Приёмка схем перед вёрсткой

- [ ] Постоянный покупатель узнаёт магазин и быстро находит знакомые разделы.
- [ ] B2C может выбрать корзинку по весу теста, форме и перейти к покупке.
- [ ] B2B видит самостоятельную посадочную и заявку из карточки с предзаполненным SKU.
- [ ] Карточка раскрывает габариты, вместимость, цену, наличие и способ действия.
- [ ] Корзина и фильтры понятны на мобильном устройстве.
- [ ] У шаблонов есть SEO-зоны: title/H1/description, breadcrumbs, контент, JSON-LD из реальных данных.
- [ ] Не используются старые предупреждения COVID, сомнительные акции и непроверенные сроки/условия доставки.
- [ ] Все кликабельные действия в прототипе дают демонстрационный результат; реальные платежи/заявки не отправляются.
- [ ] После утверждения схем есть карта соответствия legacy URL → новый URL.

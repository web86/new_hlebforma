# Hleb-Forma — новый интернет-магазин

Рабочий репозиторий: исследование старого OpenCart, план миграции на MODX 3 + MiniShop3, стратегия для розницы и оптовых пекарен, прототипы UI/UX.

## Предпросмотр сайта

**[Открыть последнюю версию прототипа v3](https://web86.github.io/new_hlebforma/)** — ссылка на GitHub Pages после завершения автопубликации.

- [Главная v3](./prototype/v3/index.html) — полноширинный хлебный fade-слайдер, белая шапка, sticky-каталог из 9 товаров с hover «корзинка → хлеб».
- [Предыдущая версия v2.2](./prototype/v2/index.html) — редакционный дизайн, натуральный ротанг, слайдшоу, поиск, корзина.
- [Оптовым покупателям](https://web86.github.io/new_hlebforma/optom/) — отдельная B2B-страница с конструктором партии и локальным запросом.
- [Каталог](https://web86.github.io/new_hlebforma/katalog/) и отдельные категории — общая вёрстка `prototype/index.html`, данные в `prototype/assets/storefront-data.js`, метаданные и навигация в `prototype/assets/catalog.js`.
- [История изменений v3 и ограничения](./prototype/v3/README.md)

### Включить GitHub Pages

1. Сделать репозиторий **Public** (если это не сделано).
2. Открыть **Settings → Pages → Build and deployment → Source**.
3. Выбрать **GitHub Actions** (не «Deploy from a branch»).
4. Открыть **Actions → Publish storefront prototype to GitHub Pages** и при необходимости нажать **Run workflow**.
5. Дождаться успешного deployment; в Settings → Pages GitHub покажет опубликованный адрес. Для репозитория `web86/new_hlebforma` стандартный адрес — https://web86.github.io/new_hlebforma/.

После настройки любое изменение главной или ассетов в `prototype/` автоматически публикуется из ветки `main`.

**Важно:** Pages публикует только `index.html` и папку `prototype/`, а не приватные технические документы. Не коммитить пароли, реальные клиентские данные и конфигурации с секретами.

## О новой концепции

В новом интерфейсе акцент на **корзинках из натурального ротанга**, помощь с выбором для домашнего хлебопечения и комплектацию профессиональных пекарен. Природные материалы — визуальное и товарное позиционирование, **не утверждение наличия экологической сертификации, биоразлагаемости всех материалов или иных непроверенных свойств**.

Проект пока **демонстрационный**, с условными ценами/характеристиками и внешними иллюстрациями. Он не принимает заказы, платежи и персональные данные. Перед запуском необходимо подтвердить материалы, складские остатки, реальные цены, отзывы и маркетинговые заявления у владельца.

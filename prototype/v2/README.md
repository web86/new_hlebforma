# Hleb-Forma — концепция главной страницы v2

Новая **самостоятельная** редакционная дизайн-концепция главной страницы. Создана как альтернатива старому [прототипу v0.3](../index.html), который остаётся доступным для сравнения.

## Открыть

- Открой [index.html](./index.html) в браузере или через статический сервер.
- Для GitHub Pages нужно выбрать **публичный** репозиторий и опубликовать `prototype/v2/` в корне Pages-сайта либо настроить соответствующий путь.
- Логотип: [assets/logo.svg](./assets/logo.svg) — исходный SVG, предоставленный для проекта.

## Основные изменения

- Цельный современный визуальный язык: светлый фон, крупные фото, теплота хлебопекарной темы, тёмная типографика; меньше одинаковых рядов карточек.
- Сильный split-hero с эмоциональным изображением хлеба и кликабельной подсказкой по конкретной корзинке.
- Мобильная горизонтальная шапка без большого поискового поля.
- Полноэкранный поиск по демонстрационному ассортименту и статьям; подсказки сразу во время ввода (Ctrl/⌘+K, Esc).
- Категории с крупными изображениями, товарные карточки, подбор по весу теста, тематический промоблок, редакционная статья «Зачем нужна корзинка».
- Отдельное визуальное предложение оптовым покупателям, отзывы и блок публикаций.
- Демонстрационные избранное, сравнение и корзина. Ничего не отправляется и не оплачивается.

## Что ещё нужно перед использованием на реальном сайте

- **Фотографии:** часть ссылок ведёт на старый hleb-forma.ru и внешние фотохостинги. В некоторых средах изображения могут не загрузиться. Получить исходные фотографии с правами использования, перенести в проект локально и заменить иллюстративные кадры.
- **Отзывы:** в концепции используются краткие выдержки/пересказы опубликованных отзывов как демонстрационное оформление. Сверить дословный текст, имя, дату и источник перед публикацией.
- **Цены и склад:** цена в карточках, география склада, остатки и доставка требуют проверки в исходной базе/у владельца; не использовать их как действующие коммерческие предложения.
- **Ссылки:** некоторые переходы на рабочие страницы указывают на старый демонстрационный прототип `../index.html#...`. Для MODX 3 они будут заменены на реальные SEO URL.
- **Каталог/поиск:** демонстрационный набор из 4 моделей. Реальные фильтрация, цены, отзывы, учётная запись и checkout должны работать с MiniShop3 и серверными интеграциями.
- **Тестирование:** проверена базовая интерактивность в Chromium: поиск по SKU, подбор по весу и открытие корзины; тест мобильного viewport 390 px не выявил горизонтального скролла. Внутренняя среда заблокировала загрузку внешних изображений, поэтому изображения нельзя считать визуально проверенными.

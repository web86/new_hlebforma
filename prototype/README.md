# Hleb-Forma — кликабельный UX-прототип v0.1

Прототип пяти ключевых страниц будущего сайта — **не работающий интернет-магазин**.

## Как открыть

1. Откройте [index.html](./index.html) локально в браузере или через простейший статический HTTP-сервер.
2. Через меню переходите между главной, каталогом, оптовой страницей и корзиной.
3. Из каталога открывайте карточки товаров; фильтруйте по форме и весу теста.
4. Добавляйте демонстрационные товары в корзину.
5. В товарной карточке нажмите «Запросить оптовую цену» — откроется форма с выбранным артикулом.

Без сборщика, npm, внешних CSS/JS и зависимостей. Маршрутизация внутри файла через `#home`, `#catalog`, `#product-bn10`, `#wholesale`, `#checkout`.

## Что доступно

- Desktop/mobile-макет с адаптивной навигацией.
- Главная с двумя маршрутами: **для себя** / **для пекарни и опта**.
- Категории, подбор по весу теста, форме и поиск по демонстрационным товарам.
- Карточка с характеристиками, «В корзину» и «Запросить оптовую цену».
- Демо-корзина с количеством и промежуточной суммой товаров.
- Оптовая форма и тестовый checkout с браузерной валидацией полей.
- Заглушки информационных страниц, подсказки про реальный контент и SEO.

## Что НЕ работает (намеренно)

- Нет сервера, базы данных, реальных заказов, реальных B2B-заявок, SMTP и подписок.
- Не подключены MiniShop3, ЮKassa, СДЭК и реальные тарифы доставки.
- Не выполняются реальные платежи; форма не сохраняет персональные данные.
- Корзина хранится только в памяти страницы и обнуляется при перезагрузке.
- Нет действующей авторизации/личного кабинета.
- Цена, комплектация, наличие и часть характеристик товара **демонстрационные**. Не использовать их для коммерческой публикации.
- Рисунки товаров **не являются фотографиями Hleb-Forma**. Заменить изображениями из действующего магазина после сверки прав и SKU.
- Шапка содержит временный текстовый бренд и условный знак; нужно заменить на оригинальный логотип.
- SEO-адреса в прототипе основаны на hash-навигации, они **не являются** планируемыми URL production.

## Критерии утверждения

См. [схемы страниц](../docs/SITE_WIREFRAMES.md), [концепцию дизайна](../docs/PROTOTYPE_BRIEF.md), [маркетинговую стратегию](../docs/MARKETING_STRATEGY.md).

При согласовании проверить **два пути**:

**Розница:** главная → подобрать корзинку по весу → каталог → карточка → корзина → демо-оформление.

**Опт:** главная/карточка → оптовикам → SKU/количество → демо-заявка.

После утверждения:
- сверить логотип, палитру, реальный каталог/фотографии/цены и существующие URL;
- собрать шаблоны на MODX 3 + MiniShop3;
- подключить серверные API и средства защиты форм/платежей;
- реализовать оригинальные данные и проверенное содержимое без рекламных обещаний, не подкреплённых источниками.

**Запуск прототипа не означает публикацию действующего магазина.**

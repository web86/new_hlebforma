# Hleb-Forma — кликабельный UX-прототип v0.1

Прототип пяти ключевых страниц будущего сайта — **не работающий интернет-магазин**.

## Как открыть

1. Откройте [index.html](./index.html) локально в браузере или через простейший статический HTTP-сервер.
2. Через меню переходите между главной, каталогом, оптовой страницей и корзиной.
3. Из каталога открывайте карточки товаров; фильтруйте по форме и весу теста.
4. Добавляйте демонстрационные товары в корзину.
5. В товарной карточке нажмите «Запросить оптовую цену» — откроется форма с выбранным артикулом.

Без сборщика, npm, внешних CSS/JS и зависимостей. Маршрутизация внутри файла через `#home`, `#catalog`, `#product-bn10`, `#wholesale`, `#checkout`.

## Что доступно

- Desktop/mobile-макет с адаптивной навигацией.
- Главная с двумя маршрутами: **для себя** / **для пекарни и опта**.
- Категории, подбор по весу теста, форме и поиск по демонстрационным товарам.
- Карточка с характеристиками, «В корзину» и «Запросить оптовую цену».
- Демо-корзина с количеством и промежуточной суммой товаров.
- Оптовая форма и тестовый checkout с браузерной валидацией полей.
- Заглушки информационных страниц, подсказки про реальный контент и SEO.

## Что НЕ работает (намеренно)

- Нет сервера, базы данных, реальных заказов, реальных B2B-заявок, SMTP и подписок.
- Не подключены MiniShop3, ЮKassa, СДЭК и реальные тарифы доставки.
- Не выполняются реальные платежи; форма не сохраняет персональные данные.
- Корзина хранится только в памяти страницы и обнуляется при перезагрузке.
- Нет действующей авторизации/личного кабинета.
- Цена, комплектация, наличие и часть характеристик товара **демонстрационные**. Не использовать их для коммерческой публикации.
- Рисунки товаров **не являются фотографиями Hleb-Forma**. Заменить изображениями из действующего магазина после сверки прав и SKU.
- Шапка содержит временный текстовый бренд и условный знак; нужно заменить на оригинальный логотип.
- SEO-адреса в прототипе основаны на hash-навигации, они **не являются** планируемыми URL production.

## Критерии утверждения

См. [схемы страниц](../docs/SITE_WIREFRAMES.md), [концепцию дизайна](../docs/PROTOTYPE_BRIEF.md), [маркетинговую стратегию](../docs/MARKETING_STRATEGY.md).

При согласовании проверить **два пути**:

**Розница:** главная → подобрать корзинку по весу → каталог → карточка → корзина → демо-оформление.

**Опт:** главная/карточка → оптовикам → SKU/количество → демо-заявка.

После утверждения:
- сверить логотип, палитру, реальный каталог/фотографии/цены и существующие URL;
- собрать шаблоны на MODX 3 + MiniShop3;
- подключить серверные API и средства защиты форм/платежей;
- реализовать оригинальные данные и проверенное содержимое без рекламных обещаний, не подкреплённых источниками.

**Запуск прототипа не означает публикацию действующего магазина.**


## Обновление v0.2 — 22 ноября 2026

По запросу владельца проекта добавлены:

- Блоки отзывов на главной и в карточке товара. Сейчас это **заглушки**, а не вымышленные отзывы. Позже импортируем реальные отзывы из OpenCart.
- Промо-блок на главной и отдельный экран «Распродажа»; **скидки и акционные товары не выдуманы**, ожидают реальных правил и данных.
- Компактное сообщение «Склад в Москве» и осторожное пояснение про уточнение наличия конкретного SKU. **Подтвердить расположение склада и место отправки** до публикации.
- Демо-кабинет без настоящей авторизации; будущие разделы: заказы, профиль, адреса, подписка, избранное, сравнение.
- Избранное и сравнение товаров до 4 моделей. Состояние хранится только **в памяти текущей страницы**, не на сервере и не в localStorage.
- Информационный блок «Что такое корзинки для расстойки теста» и блок «Почему покупают у Hleb-Forma».
- Кнопки избранного и сравнения в каталоге и карточке товара, счётчики в шапке.

**Новые маршруты:** `#sale`, `#favorites`, `#compare`, `#account`. Все обозначения цен в карточках — демонстрационные. Схемы и технические требования обновлены в [SITE_WIREFRAMES.md](../docs/SITE_WIREFRAMES.md).

**Важно:** прототип не подключён к MiniShop3. Не использовать его как production-магазин и не направлять покупателей на его формы.

## Обновление v0.3 — 23 ноября 2026

**Цель:** сделать прототип не только функциональным, но визуально цельным и более близким к исходному магазину и приложенному логотипу.

- Подключён **оригинальный SVG-логотип**, предоставленный для проекта: [assets/bakery-logo.svg](./assets/bakery-logo.svg). Он заменяет временный условный знак.
- Цветовая основа переосмыслена по логотипу: тёмный шоколадный `#4B1D07`, золотистые и медовые акценты, светлый нейтральный фон. Это концепция — не заявленная копия старой CSS-палитры.
- Шапка компактнее; иконки избранного, сравнения, кабинета и корзины стоят **горизонтально**.
- Строка поиска в шапке заменена иконкой. По клику — **полноэкранный поиск с живыми результатами** по демонстрационным товарам и статьям, без перезагрузки. Клавиши Esc / Ctrl+K (или Cmd+K).
- Главная использует более разнообразную композицию: асимметричный hero, товарный фотоколлаж, неоднотипные категории, контрастный блок опта, редакционные промо, более лёгкие преимущества и отзывы.
- Добавлены реальные изображения отдельных моделей по **прямым URL действующего hleb-forma.ru**; картинки могут быть недоступны извне и в таком случае остаётся нарисованная заглушка. Перед production изображения необходимо перенести на собственный хостинг, сохранить авторство и заменить на оригиналы достаточного разрешения.
- Лёгкие hover-эффекты в каталоге/фотографиях, отключаемые при настройке `prefers-reduced-motion`.
- Логика демо-корзины, избранного, сравнения, оптовой заявки и навигации сохранена.

**Ограничения:** поиск работает по небольшому демонстрационному набору данных, а не полной БД. Ссылка на статью ведёт в раздел статей. Поиск реального сайта потребуется реализовать через MODX/MiniShop3 и индекс контента. Прототип остаётся одностраничным HTML с hash-навигацией; URL production должны использовать обычные страницы и сохранение старой SEO-структуры.

**Рекомендации для следующей итерации:**
1. Проверить визуально desktop, tablet и mobile в реальном браузере; особое внимание ширинам 360–430 px.
2. Утвердить набор фотографий высокого разрешения, старый и новый логотип (если нужен полный фирменный нейминг), изображение склада/упаковки.
3. Заполнить главную настоящими отзывами и акциями, вместо макетов.
4. Проработать финальные отдельные экраны каталога, товара и checkout после утверждения общего визуального языка.
5. Развернуть публикацию GitHub Pages в **отдельном публичном репозитории**, не публикуя приватные документы с доступами/данными.

# Прототип главной v3 — Full-width hero + sticky catalog

**Основная ссылка GitHub Pages:** https://web86.github.io/new_hlebforma/  
**Прямой адрес v3:** https://web86.github.io/new_hlebforma/prototype/v3/  
**Предыдущая версия:** https://web86.github.io/new_hlebforma/prototype/v2/

## Что реализовано

- Полноширинная обложка с тремя фотографиями хлеба, белым жирным заголовком и двумя кнопками. Слева — затемняющий градиент для читаемости. Переходы fade каждые 7 секунд, стрелки, точки и пауза.
- Белая прозрачная шапка без нижней рамки. Оригинальный SVG-логотип встроен в HTML и не зависит от путей.
- Светлая полоса под слайдером без декоративных границ.
- Каталог: слева sticky-заголовок, подпись рукописным оранжевым шрифтом Caveat, описание и «Весь каталог»; справа 3×3 сетка **девяти** моделей с тонкими границами на белом фоне.
- При hover/focus корзинка переключается на иллюстративную фотографию готового хлеба; на мобильном — отдельная кнопка «Показать хлеб».
- Демо-корзина, избранное, сравнение и полноэкранный поиск сохранены из v2. Остальные секции о натуральных материалах, оптовых закупках, распродаже и отзывах оставлены ниже.

## Мобильный первый экран (до 640 px)

- Статичная фотография `assets/hero-bread.webp` без затемнения, отдельный светлый блок заголовка и краткого описания, полноширинная кнопка каталога и текстовая ссылка для опта.
- Высота шапки 64 px. Поиск, избранное, корзина и меню сохранены; личный кабинет доступен из меню.
- Перед каталогом остаются натуральный ротанг и доставка по России; подбор размера и помощь с выбором — после карточек. На мобильном сокращены отступы и повторяющееся описание каталога.
- При ширине от 641 px сохраняются прежняя композиция, три слайда, четыре преимущества и управление автопереключением. При смене ширины слайдер останавливается/возобновляется с учётом настроек пользователя.

## Каталог и SEO-адреса

- Общий каталог опубликован по `/katalog/`, десять исторических категорий — по своим исходным алиасам. GitHub Pages добавляет завершающий слеш; при переносе на MODX использовать исходные адреса без слеша и настроить единую каноникализацию.
- Каждая категория получает собственные HTML title, meta description, H1, текст, ссылки на товары и canonical предпросмотра. `noindex, nofollow` сохраняется на всех страницах предпросмотра. В рабочем магазине canonical и индексирование должны быть настроены на hleb-forma.ru.
- Страницы генерируются скриптом `prototype/build-catalog-pages.cjs` при сборке из общего шаблона, каталога и данных. Список исходных адресов: `HlebCatalog.pages` в `prototype/assets/catalog.js` (поле `legacyPath`).
- Треугольные и квадратные формы, сердечки и ромбы используют исторические объединённые категории; параметр `shape` выбирает конкретную форму внутри раздела, не создавая новый SEO-алиас. Категории без загруженных моделей показывают ссылку на действующий магазин, без выдуманных товаров.
- Шапка ведёт в общий каталог, третий экран главной — в соответствующие категории. Кнопка выбора на первом экране остаётся якорем на подборку главной; рисунки на заказ — контактной ссылкой.

## Проверки и ограничения

- В каталоге главной показаны BN 001, BN 09, BN 11, BN 24, BN 26, BN 27, BN 28, BN 29, BN 30. Первые три — со скидками; базовые цены и характеристики сверены с действующим магазином. Размер BN 24 указан по заголовку товара; вместимость BN 29 не указана в исходном каталоге.
- Для всех девяти карточек используются предоставленные WebP-фотографии из `prototype/assets/products/`; BN 09 и BN 24 имеют одинаковый исходник. При наведении используются локальные иллюстрации готового хлеба, подобранные по форме.
- Фоновые фотографии с внешнего сервиса могут быть недоступны в отдельных браузерных средах. Для производства нужны собственные крупные исходники с корректной лицензией, а изображения товаров нужно хранить локально.
- Контентные ссылки ведут на предыдущий прототип (`../index.html#...`) там, где отдельные страницы MODX ещё не разработаны.
- Реальные checkout, управление отзывами, наличие в Москве, скидки, верифицированные отзывы, согласия и CRM отсутствуют.
- Заголовки/подписи не содержат неподтверждённых заявлений об эко-сертификатах или «100% экологичности». Натуральный ротанг — основная тема страницы.
- SVG встроен inline, шапка и каталог адаптивны, для пользователей с `prefers-reduced-motion` автослайдер выключен.
- JavaScript прошёл синтаксическую проверку. Полное браузерное функциональное/визуальное тестирование ещё требуется.

## Что проверить при просмотре

1. Как читается белый текст на всех трёх слайдах, включая мобильный размер.
2. Центрирование и ширину секций в диапазоне 360–1440 px.
3. Sticky левой колонки при прокрутке справа девяти товаров.
4. Hover фото корзинки → хлеб; на телефоне — кнопка переключения.
5. Кнопки покупки, избранного, поиска, управления слайдером и переходы в старый демо checkout.

Затем подтвердить у владельца реальные цены, качество фотографий девяти карточек и отзывы. После утверждения стилистики — перенести интерфейс в шаблоны MODX 3 / MiniShop3.
